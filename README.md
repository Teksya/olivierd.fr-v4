# olivierd.fr - v4

Portfolio minimal en Express.js + Tailwind CSS (CDN) - style sobre, élégant et moderne.

## Installation

1. Installer dépendances

```bash
npm install
```

2. Démarrer

```bash
npm start
# ou en dev
npm run dev
```

3. Ouvrir http://localhost:3000

## Structure

- [package.json](package.json)
- [server.js](server.js)
- [views](views) - templates EJS
- [public](public) - styles et assets

Remplacez les contenus des pages par vos textes et images, puis déployez sur votre hébergeur préféré.
